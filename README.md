# TripMate — AI Travel Assistant

TripMate is an AI travel assistant built as a tool-using agent. It accepts natural-language travel questions from a command-line interface, dynamically selects the relevant tools, retrieves destination information from a Pinecone-backed RAG system, retrieves weather information from a weather tool, and synthesizes the results into one response.
